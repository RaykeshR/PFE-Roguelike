Options d'Installation du Jeu

Le jeu PFE-Roguelike est disponible via plusieurs méthodes d'installation pour s'adapter à vos préférences.

1. Installeur Windows (Recommandé)

La méthode la plus simple pour installer le jeu sur Windows. Cet installeur vous guidera à travers les étapes nécessaires.

  • Version: v2.6.0.86 (dernière version stable)
  • Télécharger l'installeur (.exe)

Note: L'installeur a été créé avec Inno Setup.

2. Versions Exécutables Python (Avancé)

Ces versions sont générées par PyInstaller. Elles sont portables mais peuvent nécessiter une configuration manuelle du fichier .env si vous souhaitez vous connecter à une base de données. Ces versions sont principalement destinées aux développeurs ou aux utilisateurs souhaitant une portabilité maximale sans installation complète.

Version OneFolder (avec console)

Cette version génère un dossier contenant l'exécutable et toutes ses dépendances. Une console est visible lors de l'exécution.

  • Fichier: PFE-Roguelike.exe
  • Télécharger PFE-Roguelike (Dossier Complet)

Version OneFile (avec console)

Cette version génère un seul fichier exécutable. Une console est visible lors de l'exécution.

  • Fichier: PFERoguelike.exe
  • Télécharger PFERoguelike (Fichier Unique)

Version OneFile (sans console)

Similaire à la version OneFile, mais l'exécutable se lance sans afficher de fenêtre de console, idéal pour une expérience utilisateur plus fluide.

  • Fichier: Roguia.exe
  • Télécharger Roguia (Fichier Unique sans Console)

Important: Pour ces versions PyInstaller, assurez-vous que le fichier de configuration .env (contenant les informations de connexion à la base de données) est placé à côté de l'exécutable pour un fonctionnement optimal.
