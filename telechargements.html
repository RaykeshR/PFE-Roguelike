Options d'Installation du Jeu

Le jeu PFE-Roguelike est disponible via plusieurs méthodes d'installation pour s'adapter à vos préférences.

1. Installeur Windows (Recommandé)

La méthode la plus simple pour installer le jeu sur Windows. Cet installeur vous guidera à travers les étapes nécessaires.

  • Version : v2.6.0.86 (dernière version stable)
  • Télécharger l'installeur (.exe)

Note : L'installeur a été créé avec Inno Setup.

2. Versions Exécutables (Pour utilisateurs avancés)

Ces versions sont générées par PyInstaller. Elles sont portables mais peuvent nécessiter une configuration manuelle. Ces versions sont principalement destinées aux développeurs ou aux utilisateurs souhaitant une portabilité maximale sans installation complète.

Version "OneFolder" (avec console)

Cette version est un dossier contenant l'exécutable et toutes ses dépendances. Une console est visible lors de l'exécution.

  • Télécharger PFE-Roguelike (Dossier)

Version "OneFile" (avec console)

Cette version est un seul fichier exécutable. Une console est visible lors de l'exécution.

  • Télécharger PFERoguelike (Fichier unique)

Version "OneFile" (sans console)

Similaire à la version "OneFile", mais l'exécutable se lance sans afficher de fenêtre de console.

  • Télécharger Roguia (Fichier unique sans console)

Important : Pour ces versions, assurez-vous que le fichier de configuration .env est placé à côté de l'exécutable pour un fonctionnement optimal.
